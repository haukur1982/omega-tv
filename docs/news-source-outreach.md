# News source outreach — draft emails

Eight personalized first-contact emails for the Christian news sources we want to translate from. Send each one once. Most will reply with a yes; the rest you can follow up on or skip.

**Floor practice we're committing to in every email:**
- 2–3 paragraph Icelandic summaries (not full reposts)
- Source name credited prominently at the top
- Direct link back to the original article
- Non-commercial, ministry purpose
- Readers go to the original publisher for full text + images

**Don't wait for everyone to reply before launching.** Start publishing under the floor practice. Update if any source pushes back.

## After sending

When a source replies with a yes (or no reply within 2 weeks → assume yes under floor practice):
1. Note the response in this doc (date, who replied, any specific guidelines).
2. Add the source name to your standard "sourceName" set in the admin UI so it's pre-fillable.

When a source pushes back:
- Stop publishing summaries from that source immediately.
- Reply asking what they'd accept (e.g. shorter excerpts, fewer per week, syndication fee).
- Update this doc.

**Documenting matters** — if anyone ever asks "did you have permission?", you have a paper trail.
